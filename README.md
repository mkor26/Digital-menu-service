#  Digital Menu Service

##  Назначение

Сервис предназначен для создания, редактирования и просмотра электронного меню
заведений общественного питания (кафе, ресторанов, баров, кофеен).
Приложение позволяет заменить бумажные меню цифровыми, оперативно обновлять
цены и состав блюд.


## Целевая аудитория

**Владельцы и администраторы заведений** - для управления меню, ценами и акциями.
**Официанты и персонал** - для быстрого доступа к актуальному меню.
**Посетители** - для просмотра меню со смартфона без ожидания официанта.


## Описание предметной области

Предметная область - автоматизация процесса формирования и предоставления
меню в заведениях общественного питания. Традиционные бумажные меню требуют
перепечатки при изменении цен или состава блюд, что ведёт к дополнительным
затратам и ошибкам. Электронное меню решает эти проблемы: изменения вносятся
в одном месте и мгновенно отображаются у всех посетителей.


## Основные сущности

- блюдо - Позиция меню: название, описание, состав, цена
- категория - Раздел меню (напитки, супы, десерты и т. д.)
- ресторан - Место, которому принадлежит меню
- состав - Продукты из которых состоит блюдо 


## Основные функции

- show_dish - просмотр информации о блюде.
- check_availability - Проверка доступности блюда.
- calculate_order - расчет стоимости заказа.
